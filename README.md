\# Gestor de Tareas



\## Estructura del proyecto



\- `index.html`: página principal del proyecto.

\- `README.md`: documentación del proyecto.



\## Estructura de index.html



\- `html`: contiene el documento HTML.

\- `head`: contiene información de la página.

\- `title`: establece el título de la página.

\- `body`: contiene el contenido visible.

\- `h1`: muestra el título principal.

\- `h2`: muestra el apartado de tareas pendientes.

\- `ul`: crea una lista de tareas.

\- `li`: representa cada tarea de la lista.
